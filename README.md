# ngx-kit

Reusable Angular UI components, directives, and utilities.

The library is published as `ngx-kit` and exposes feature-specific entry points so applications can import only the pieces they use.

```bash
npm install ngx-kit
```

For the package catalogue, installation requirements, shared styles, and links to feature documentation, see [the library README](projects/libs/README.md).

## Development

This repository contains the Angular demo application and the library source.

```bash
npm install
npm run start
```

Build the library with:

```bash
npm run build:lib
```

Run the library tests with:

```bash
npm run test:libs
```

Before publishing, build the package and inspect the generated `dist/ngx-kit` output and npm package contents.
